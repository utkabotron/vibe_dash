# Быстрый старт

## 1. Создайте файл `.env.local`

```bash
# В корне папки Dashboard создайте файл .env.local
# Скопируйте туда содержимое из ENV_SETUP.md
```

## 2. Запустите проект

```bash
npm run dev
```

## 3. Откройте браузер

Перейдите на [http://localhost:3000](http://localhost:3000)

## Что вы увидите

- **Фильтры** - выбор проектов, сотрудников, дат и т.д.
- **KPI карточки** - общая статистика
- **Графики**:
  - Часы по проектам (с разбивкой по сотрудникам)
  - Часы по сотрудникам
  - Распределение по операциям
  - Динамика во времени
- **Таблицы** - детальная информация по проектам, сотрудникам и изделиям

## Возможные проблемы

### Ошибка "Failed to fetch data"

Проверьте:
1. Файл `.env.local` создан и содержит правильные credentials
2. Service Account имеет доступ к Google Sheets
3. ID таблицы в `src/lib/sheets.ts` совпадает с вашей таблицей

### Пустые данные

Убедитесь, что:
1. Лист называется "Reports"
2. Структура колонок соответствует ТЗ
3. Есть данные в таблице

## Структура данных

Лист должен содержать колонки:
- timestamp
- employee_name
- project_name
- product_id
- category
- subcategory
- category_name
- quantity
- unit
- comment
