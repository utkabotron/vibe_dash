# Changelog

## [Версия от 05.11.2025]

### Добавлено
- **Фильтр по месяцам** с мультивыбором
  - Дропдаун для выбора месяцев (формат: "Октябрь 2025")
  - Возможность выбрать несколько месяцев одновременно
  - Выбранные месяцы отображаются зелеными чипсами
  - Автоматическое извлечение уникальных месяцев из данных
  - Хронологическая сортировка месяцев

### Изменено
- Фильтры теперь размещены в один ряд (4 колонки: Проект, Изделие, Сотрудник, Месяц)
- Обновлена сетка фильтров с `md:grid-cols-3` на `md:grid-cols-4`
- Счетчик активных фильтров теперь учитывает выбранные месяцы

### Технические изменения
- Добавлено поле `months: string[]` в тип `FilterState`
- Реализована функция `getUniqueMonths()` в `analytics.ts`
- Обновлена функция `filterReports()` для поддержки фильтрации по месяцам
- API `/api/data` теперь принимает параметр `months` и возвращает список доступных месяцев
- Обновлен компонент `Filters` с новым UI элементом для месяцев

### Исправлено
- Исправлена проблема с парсингом дат в формате `dd-MM-yy`
- Добавлена поддержка двузначных годов (автоматическое добавление 2000)

## Деплой

### Требования
- Node.js 18+
- Next.js 15.0.3 (важно: версия 16.0.1 имеет баги при сборке)
- Google Sheets API credentials

### Процесс деплоя
1. Локальная сборка с Next.js 15.0.3
2. Создание архива `.next` папки
3. Загрузка на сервер через SCP/SFTP
4. Распаковка и перезапуск через PM2

### Известные проблемы
- Next.js 16.0.1 имеет баг при локальной сборке (`workUnitAsyncStorage`)
- Несовместимость версий Next.js между локальной сборкой и сервером приводит к ошибкам
- На сервере недостаточно памяти для сборки, поэтому сборка выполняется локально
